# Прогнозирование цен на недвижимость (King County)

Это проект по исследованию данных и оценке стоимости жилья в округе Кинг (штат Вашингтон, США). 

Главная цель — разобраться, из чего складывается цена на дом, очистить данные от «мусора» и странных выбросов, а затем обучить модель, которая сможет точно предсказывать стоимость недвижимости.

---

## Какие технологии использовались

- **Язык:** Python 3.12
- **Работа с данными:** `pandas`, `numpy`
- **Визуализация:** `matplotlib`, `seaborn`
- **Машинное обучение:**
  - `scikit-learn` — подготовка данных (`StandardScaler`), кластеризация (`KMeans`, `DBSCAN`) и расчет метрик ошибки (`MAE`, `R²`, `MAPE` и др.).
  - `lightgbm` — основной алгоритм градиентного бустинга для предсказания цен.
- **Интерпретация:** `shap` — чтобы наглядно показать, какие именно параметры дома больше всего влияют на итоговый ценник.

---

## Как проходило исследование

1. **Знакомство с данными:** Разбор структуры датасета `kc_house_data.csv`, поиск пропущенных значений и скрытых дубликатов.
2. **Очистка от аномалий:** Поиск нереалистичных записей. *Например, нашелся дом с 33 спальнями при скромной площади всего в 1620 кв. футов — явно опечатка, такие вещи мы убрали.*
3. **Кластеризация и фичи:** Сгруппировали объекты с помощью `KMeans` и `DBSCAN`, чтобы найти скрытые типы жилья и выделить интересные закономерности.
4. **Обучение модели:** Настроили модель `LightGBM` и оценили точность предсказаний с помощью метрик качества.
5. **Анализ результатов (SHAP):** Заглянули внутрь «черного ящика» модели и выяснили, что сильнее всего меняет стоимость — площадь, район или качество постройки.

---

## О датасете

Используется классический набор данных **King County House Sales**:
- Содержит данные о продажах домов с мая 2014 по май 2015 года.
- **Ключевые поля:** цена (`price`), количество спален и ванных, жилая площадь (`sqft_living`), площадь участка, этажность, вид на воду (`waterfront`), оценка состояния (`grade`), год постройки и географические координаты (`lat`, `long`).
